# Annuaire des ressources

Une sélection de dépôts publics utiles autour de Claude Code, contrôlés un par un. Pour les mêmes ressources classées par domaine d'usage, avec le moment où chacune sert, voir [annuaire-par-domaine.md](annuaire-par-domaine.md).

> **Méthode et fraîcheur.** Chaque dépôt ci-dessous a été vérifié en direct le **2026-06-22**. Les nombres d'étoiles sont des ordres de grandeur à cette date : ils évoluent vite, ne les prenez pas au mot. Si vous trouvez un lien mort ou un dépôt abandonné, signalez-le (voir [CONTRIBUTING.md](CONTRIBUTING.md)).

## Officiel (Anthropic)

À consulter en premier, toujours.

| Dépôt | Pour quoi | Repère (2026-06-22) |
|---|---|---|
| [code.claude.com/docs](https://code.claude.com/docs/en/overview) | La documentation qui fait autorité | Source officielle |
| [anthropics/claude-code](https://github.com/anthropics/claude-code) | Le dépôt du CLI : issues, changelog, exemples | ~134 000 étoiles, très actif |
| [anthropics/skills](https://github.com/anthropics/skills) | Les skills officiels et le standard ouvert | ~154 000 étoiles, actif |
| [anthropics/claude-plugins-official](https://github.com/anthropics/claude-plugins-official) | Le marketplace de plugins officiel et curé | ~30 600 étoiles, actif |
| [anthropics/claude-plugins-community](https://github.com/anthropics/claude-plugins-community) | Le marketplace communautaire, relu par Anthropic | ~200 étoiles, actif |
| [anthropics/claude-code-action](https://github.com/anthropics/claude-code-action) | La GitHub Action officielle (intégration continue) | ~8 100 étoiles, actif |
