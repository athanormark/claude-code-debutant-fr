# Contribuer

Merci de vouloir améliorer ce parcours. Quelques règles simples pour que les contributions restent utiles.

## L'esprit du dépôt

Ce projet est volontairement **opinionné et resserré**. Son but n'est pas de tout lister, d'autres dépôts le font très bien et on les cite, mais d'offrir un chemin clair à un débutant. Une contribution qui clarifie ou corrige a beaucoup plus de valeur qu'une contribution qui ajoute du volume.

## Contributions les plus utiles

1. **Corrections de faits.** Une commande qui a changé, un comportement qui a évolué. Indiquez la source officielle.
2. **Liens morts ou dépôts abandonnés.** L'écosystème bouge vite, l'annuaire se périme.
3. **Coquilles et formulations confuses.** Le français doit rester impeccable et accessible.
4. **Traductions.** La version anglaise du parcours est sur la feuille de route.

## Règles de contenu

- **Aucun chiffre inventé.** Tout dépôt cité doit exister et être vérifiable. Les étoiles GitHub évoluent, donc on date les chiffres et on évite de les multiplier.
- **Sources officielles d'abord.** Pour un fait technique, la référence est [code.claude.com/docs](https://code.claude.com/docs/en/overview).
- **Français correct.** Accents, ponctuation française, pas de jargon non expliqué.
- **Pas de promotion déguisée.** On peut citer un outil utile, pas en faire la réclame.

## Marche à suivre

1. Ouvrez d'abord une issue pour discuter d'un changement de fond, avant d'écrire.
2. Pour une petite correction, une pull request directe suffit.
3. Un changement par pull request, avec un titre clair.
4. Les ajouts de ressources doivent préciser le lien, une description d'une ligne et la date de vérification.

Les pull requests qui élargissent le périmètre au-delà d'un parcours débutant pourront être refusées, sans que cela retire leur valeur. L'objectif reste la clarté.
