# Code de conduite

## Notre engagement

Ce projet accueille toute personne qui veut apprendre ou aider, quels que soient son niveau, son parcours ou son origine. Débuter n'est jamais une question idiote.

## Comportements attendus

- Rester courtois et constructif, surtout face à une question de débutant.
- Expliquer plutôt que juger.
- Accepter les corrections factuelles de bonne grâce, sources à l'appui.

## Comportements inacceptables

- Le harcèlement, les propos discriminatoires ou les attaques personnelles.
- La promotion abusive et le spam.
- La diffusion d'informations privées sans accord.

## Signalement

Un comportement problématique peut être signalé en ouvrant une issue, ou en privé via [atelia-conseil.com](https://atelia-conseil.com). Les signalements sont traités avec discrétion.

Ce code de conduite s'inspire des principes du Contributor Covenant.
