# Message de commit

Quand on t'appelle, produis un message de commit propre.

1. Regarde les changements préparés avec `git diff --staged`.
2. Résume l'intention en une ligne courte, à l'impératif (par exemple « Corrige le calcul de TVA »).
3. Si le changement le mérite, ajoute deux ou trois puces pour le détail.
4. Propose le message et attends la validation. Ne committe pas tout seul.

Reste factuel : décris ce que fait le changement, pas comment tu t'y es pris.
